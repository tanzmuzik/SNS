| 項目 | 設定 |

| 広告目的 | リード獲得 |
| 地域 | 鹿児島県 |
| 年齢 | 45〜65歳 |
| 性別 | 男女 |

## CTA設計（v2）

- リード獲得広告では**画面下のCTAボタンが主動線**。動画内テロップは「無料資料請求は下のボタンから」と誘導する
- QRコード表示は維持（オーガニック投稿・他媒体転用時に有効）
- オーガニック投稿用テロップは「無料資料請求はこちら」に差し替え

## 横断チェックリスト

- [ ] 縦型9:16フォーマット確認
- [ ] 音なしでもテロップだけで意味が伝わるか確認
- [ ] **冒頭テロップが0秒から表示されているか確認**（スワイプ離脱防止）
- [ ] QRコードのリンク先（無料資料請求LP）が正しいか確認
- [ ] Meta広告マネージャーでターゲット設定（鹿児島・45〜65歳）確認
- [ ] UTMパラメータをリンクに付与
- [ ] 「速度のお悩みもご相談ください」の訴求がサポート実態と一致しているか確認
- [x] 「電話はすぐつながる」→裏付けデータなしのため「スタッフが直接電話に出ます」に変更済み（自動音声ガイダンスなしは実態として確約できる）
- [ ] シーン②Aの画面文言が実在他社の表記と一致していないか確認
- [ ] シーン③のナレーション（v3短縮版）を声に出して8秒以内に収まるか再計測
