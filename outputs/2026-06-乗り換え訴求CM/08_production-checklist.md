# 制作進行チェックリスト｜プロデューサー

> 乗り換え訴求CM（30秒）制作フェーズの実行手順。
> 台本v3・絵コンテv3・素材プロンプトv3 確定済み。これに沿って制作を進める。

---

## フェーズ1：静止画素材生成（ComfyUI + Anima Base）

- [ ] Scene ①：手元・日常（05_asset-prompts.md 参照）
- [ ] Scene ②A：スマホ画面（**無地発光で生成。文字は入れない**）
- [ ] Scene ②B：LINEを打つ手元
- [ ] Scene ③A：電話サポート（スタッフ笑顔・ヘッドセット）
- [ ] Scene ③B：駆けつけ（第1案：徒歩到着）
- [ ] Scene ③B 代替：車両到着（**先に生成しておく**。歩行破綻時のリトライで時間を溶かさない）
- [ ] Scene ④A：鹿児島の空と物件（桜島入り）

**品質基準**：手指の本数破綻なし／縦9:16／②Aの画面領域はコーナーピンを貼れる平面が確保されていること

## フェーズ2：Canvaデザイン素材

- [ ] ②A用 画面UI「ただいま大変混み合っています」＋ローディング（背景透過PNG・実在他社UIと非一致）
- [ ] テロップ一式（03_script.md の文言どおり。体言止め・句読点なし）
- [ ] ④B用 CTAカード：ロゴ＋QRコード（無料資料請求LP）＋「速度の悩みも気軽に相談」

## フェーズ3：動画化（確定ルート：Veo 3.1 API＋Premiere直作）

> ローカルI2V（LTXV）はM5 Air 16GBのメモリ不足で打ち切り（09参照）。

- [ ] **②A・④B：動画生成しない**。Premiereのみで制作（フェーズ5参照）
- [ ] ①・②B・③A・③B：**Veo 3.1 Fast・4秒・720p**で生成（プロンプトは07。原則1発・失敗時1リトライまで）
- [ ] ④A：**Veo標準**で生成（品質投資はここだけ）
- [ ] ③B：車両到着案を第1案として生成
- [ ] ②B→③Aの色温度転換が成立しているか並べて確認

## フェーズ4：音声・字幕（Vrew）

- [ ] ナレーション生成（丁寧な話し言葉・句読点あり）
- [ ] **シーン③ナレーションの実測**：8秒に収まること（生成音声は想定より遅くなりがち。超過したら台本v3の短縮版を使用）
- [ ] テロップとナレーションが「同じ意味・異なる表現」になっているか最終照合

## フェーズ5：編集・仕上げ（Premiere Pro）

- [ ] ②A：Canva画面UIをコーナーピン合成＋不透明度キーフレームでローディング点滅
- [ ] 冒頭テロップ**0秒から表示**（ナレーション開始を待たない）← 前作の冒頭4秒60%離脱対策の核
- [ ] テロップは縦型セーフゾーン内（上下15%を避ける）
- [ ] ②→③で色補正の落差を強調（青灰→暖色）
- [ ] ④B：ロゴ＋QRを**2秒以上静止**
- [ ] 書き出し：9:16 / 1080×1920 / 30秒

## フェーズ6：出稿（SNSオプティマイザー）

- [ ] **先にフォーム修正単体の効果を確認**（ロケールJapanese化・確認ステップ廃止の数字を切り分け）
- [ ] LPVキャンペーンの**パターンB（フック率24%）から差し替え**
- [ ] 投稿設定は 06_posting-settings.md どおり（地域：鹿児島、45〜65歳、リード獲得）
- [ ] 配信開始後3〜4日でフック率・継続率を前作（31%/24%・継続6%）と比較
- [ ] 改善確認後にパターンAの差し替え・予算増額を判断

## 判断が必要になったら

| 状況 | 判断者 | 基準 |
|---|---|---|
| ③B歩行破綻が2回続く | 素材ディレクター | 即・車両到着案へ。リトライしない |
| ③ナレーション8秒超過 | コピーライター | 文を削る。早回しはしない |
| フック率が前作以下 | クリエイティブD | 冒頭テロップの文言・表示タイミングを再検証 |
| フォーム効果が不明瞭 | SNSオプティマイザー | CM差し替えを1週遅らせてでも切り分ける
