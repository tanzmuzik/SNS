# 制作ブリーフ｜乗り換え訴求CM

## 基本情報

| 項目 | 内容 |
|---|---|
| 商品 | シナプス光 マンションまるごとプラン |
| ターゲット | 鹿児島の個人マンションオーナー（他社インターネットを契約中） |
| 訴求の核 | 「気づいたら自分が対応している」巻き込まれ感 |
| 差別化ポイント | 電話がすぐつながる ＋ 提携業者による駆けつけサポート |
| 訴求軸 | 他社への不満・手間訴求 → シナプス光で解放 |
| 尺 | 30秒メイン |
| CTA | 無料資料請求 |

## 制作ルール

- テロップ：体言止め・句読点なし・インパクト重視
- ナレーション：丁寧な話し言葉・句読点あり
- テロップとナレーションは同じ意味・異なる表現（別内容はNG）
- 顔は映さない（手元・物件・スタッフのみ）→ 視聴者が自分を重ねやすくするため

## リサーチで見つかったオーナーのリアルな声

- 「入居者の携帯で繋がらないとのクレームが入りました」
- 「毎日のように催促メールが届くなど、ややクレーマーのように感じ始めております」
- 「埒があきません」
- 「ネット無料だから入居したのに、これでは話が違う。自分で回線ひくから、その分家賃を下げてくれ」という話になると、オーナーまで巻き込まれてしまう

## 訴求の核

> 「自分には解決できない問題なのに、巻き込まれ続ける」

オーナーの本音は「怖い」でも「面倒」でもなく、**「気づいたら自分が対応している」という理不尽さ**。
この感覚を冒頭で言い当て、「シナプス光なら巻き込まれなくて済む」で解放する。
