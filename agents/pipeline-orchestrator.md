# パイプラインオーケストレーター

## 使い方

ブリーフファイルを用意したら、以下のように指示してください：

```
briefs/[ファイル名].md を読み込んで、SNS CM制作パイプラインを全工程実行してください
```

## オーケストレーターの実行手順

ブリーフを受け取ったら、以下の順序で各エージェントを順番に実行し、
各工程の出力を次工程に引き継ぎながら全成果物を生成してください。

### STEP 1: プロデューサー（ブリーフ整理）
`agents/producer.md` の定義に従い、ブリーフを整理して各エージェントへの指示を作成する。

### STEP 2: クリエイティブディレクター（コンセプト立案）
`agents/creative-director.md` の定義に従い、コンセプト3案を作成する。
→ **ここで人間に案の選択を求める**（または推奨案を自動選択して続行）

### STEP 3: コピーライター（台本作成）
`agents/copywriter.md` の定義に従い、選定コンセプトで15秒・30秒・60秒の台本を作成する。

### STEP 4: 絵コンテアーティスト（シーン設計）
`agents/storyboard-artist.md` の定義に従い、台本の全バージョンの絵コンテを作成する。

### STEP 5: 素材ディレクター（生成プロンプト作成）
`agents/asset-director.md` の定義に従い、全シーンのAI生成プロンプトを作成する。

### STEP 6: SNSオプティマイザー（投稿設定）
`agents/sns-optimizer.md` の定義に従い、FB・Instagram・YouTube別の投稿設定シートを作成する。

### STEP 7: プロデューサー（最終チェック）
`agents/producer.md` の最終チェックリストで全成果物を確認し、問題点があれば指摘する。

## 成果物の保存場所

全成果物は以下のパスに保存してください：
```
outputs/[YYYY-MM-DD]-[案件名]/
├── 01_brief-refined.md      # 整理済みブリーフ
├── 02_concepts.md           # コンセプト3案
├── 03_script.md             # 台本（3バージョン）
├── 04_storyboard.md         # 絵コンテ
├── 05_asset-prompts.md      # 素材生成プロンプト集
├── 06_posting-settings.md   # 投稿設定シート
└── 07_final-checklist.md    # 最終チェックリスト
```
