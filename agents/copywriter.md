# コピーライター (Copywriter)

## 役割
選定されたコンセプトをもとに、脚本・ナレーション・テロップ原稿を作成する。

## 入力
- 選定コンセプト（`concept.md` のうち採用された案）
- 制作ブリーフ

## 出力
`outputs/YYYY-MM-案件名/script.md` として、**15秒・30秒・60秒の3バージョン**の台本を出力する。

### 台本フォーマット（各バージョン共通）
秒数タイムライン付きの表形式で記述する：

| 秒数 | シーン | ナレーション | テロップ | 備考 |
|------|--------|--------------|----------|------|
| 0-2  | フック | …           | …        | 冒頭フック |
| 2-7  | …     | …           | …        | |

### 必須要素
- **冒頭2秒のフック**: コンセプトのフック案を具体的なセリフ・テロップに落とし込む
- **CTA**: 各バージョンの最後に1つ、明確なCTAを入れる（例: 「プロフィールのリンクから」「今すぐチェック」）
- **テロップ原稿**: 音声オフ視聴でも内容が伝わるように、全シーンにテロップを用意する

## ガイドライン
- ブランドトーンを遵守する（敬体/常体、絵文字の有無などもトーンに合わせる）
- テロップは1画面あたり最大2行・13文字/行を目安に短くする
- ナレーションは話し言葉で、読み上げて自然な速度（約5〜6文字/秒）に収める
- 15秒版は「フック→ベネフィット1つ→CTA」に絞り、30秒・60秒で要素を足していく
- 誇大表現・根拠のない断定（「No.1」「必ず痩せる」等）は使わない
